Requirement: พัฒนาโปรแกรม SQLite Task Manager PRO ด้วย PyQt6 สำหรับจัดการงาน โดยผู้ใช้สามารถ Login เข้าระบบ เพิ่ม แก้ไข ลบ และทำเครื่องหมายงานว่าเสร็จแล้วได้ กำหนดระดับความสำคัญของงานเป็นต่ำ กลาง หรือสูง จัดหมวดหมู่งานและเพิ่ม แก้ไข หรือลบหมวดหมู่ได้ มีระบบ Search และ Filter มี Dashboard แสดงจำนวนงานทั้งหมด งานที่เสร็จแล้ว งานค้าง งานใกล้ครบกำหนด และจำนวนงานแยกตาม Category หรือ Priority สามารถเรียงลำดับงาน ส่งออกและนำเข้าข้อมูล CSV แจ้งเตือนงานใกล้ครบกำหนด Duplicate Task บันทึกเวลาที่ทำเสร็จ เปลี่ยน Theme มืด/สว่างด้วย QSettings รวมถึง Backup และ Restore ฐานข้อมูล tasks.db และสามารถสร้างเป็นไฟล์ .exe พร้อมไอคอน
UI Design ก่อน Prompt: ออกแบบหน้าจอให้แบ่งเป็นส่วน Login และหน้าหลักของ Task Manager โดยหน้าหลักมีแบบฟอร์มสำหรับกรอกชื่องาน รายละเอียด Priority Category และวันครบกำหนด พร้อมปุ่ม Add, Edit, Delete, Done และ Duplicate มีช่อง Search และ Filter สำหรับกรองสถานะ Priority และ Category แสดงรายการงานในรูปแบบตาราง และมีหน้า Dashboard สำหรับสรุปจำนวนงานแต่ละประเภท รวมถึงหน้าจัดการ Category และเมนูสำหรับ Export CSV, Import CSV, Backup, Restore และเปลี่ยน Theme เพื่อให้ใช้งานได้สะดวกและเป็นระเบียบ
แผนการทำงานเป็นขั้นตอน: เริ่มจากออกแบบฐานข้อมูล SQLite โดยสร้างตารางสำหรับผู้ใช้ งาน และหมวดหมู่ จากนั้นสร้างระบบ Login และหน้าต่าง Task Manager ด้วย PyQt6 เพิ่มฟังก์ชันสำหรับเพิ่ม แก้ไข ลบ และเปลี่ยนสถานะงาน แล้วเพิ่มระบบ Priority และ Category พร้อมหน้าจัดการหมวดหมู่ จากนั้นพัฒนา Search และ Filter รวมถึง Dashboard สำหรับสรุปข้อมูล เพิ่มการเรียงลำดับงาน ระบบแจ้งเตือนงานใกล้ครบกำหนด Duplicate Task และบันทึกเวลาที่ทำเสร็จ ต่อด้วยระบบ Export และ Import CSV โดยตรวจสอบรูปแบบข้อมูล เพิ่ม Theme มืด/สว่างด้วย QSettings และระบบ Backup/Restore ไฟล์ tasks.db เมื่อพัฒนาครบแล้วจึงทดสอบทุกฟังก์ชันและสร้างไฟล์ .exe พร้อมไอคอนสำหรับใช้งานจริง
